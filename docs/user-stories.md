# User stories du pratiquant

Toutes les situations qu'un pratiquant de musculation rencontre avec Trainerr, de l'installation au suivi sur plusieurs mois. Chaque story dit ce que l'appli fait aujourd'hui.

Légende : ✅ couvert · 🆕 ajouté dans cette série · 🔜 piste, pas encore fait.

Les personnages viennent des séances test de [retour-utilisateur.md](retour-utilisateur.md) : **Léa** débute, **Thibaut** s'entraîne déjà 4 fois par semaine en salle, **Karim** reprend après six mois d'arrêt.
