# Traduction de l'appli

Aucun texte, nombre, date ni unité n'est écrit en dur dans le code : tout passe par les fichiers de traduction et les API standard `Intl` (SPEC.md, section « Internationalisation »).

## Ce que voit l'utilisateur

- **Réglages → Langue et unités** : langue du téléphone (par défaut), français ou anglais. Le changement s'applique tout de suite, sans redémarrer.
- **Unité de poids** : kilogrammes ou livres. Les charges restent stockées en kg ; elles sont converties à l'affichage (arrondies à la demi-livre) et à la saisie.
- Nombres, dates, jours de la semaine et tri alphabétique suivent la langue (`Intl.NumberFormat`, `Intl.DateTimeFormat`, `Intl.Collator`) : « 8,5 reps » en français, « 8.5 reps » en anglais.

## Où sont les textes

| Contenu                                                     | Fichier                                                                    |
| ----------------------------------------------------------- | -------------------------------------------------------------------------- |
| Interface, fiches « Bien débuter », notifications, À propos | `src/i18n/locales/<langue>.json`                                           |
| Nom des exercices                                           | `nameEn` (source) et `nameFr` (`src/data/catalog/curated.ts`)              |
| Consignes des machines                                      | `cues` (français) et `cuesEn` (anglais) dans `src/data/catalog/curated.ts` |

Les pluriels utilisent la syntaxe de vue-i18n : `"{count} série | {count} séries"`. Les phrases gardent des emplacements nommés (`{load}`, `{template}`) : on ne colle jamais des morceaux de phrase dans le code.

## Ajouter une langue (ex. espagnol)

1. Copier `src/i18n/locales/en-US.json` en `src/i18n/locales/es-ES.json` et traduire chaque valeur, sans toucher aux clés ni aux `{emplacements}`.
2. Dans `src/i18n/index.ts` : ajouter `'es-ES'` à `supportedLocales` et le fichier à `messages`.
3. Ajouter l'option dans `settings.language.options` de chaque fichier de langue.
4. Pour le contenu : ajouter `cuesEs` aux machines de `curated.ts` (même modèle que `cuesEn`) et une colonne par migration, sur le modèle de la migration 4.
5. Lancer `npm run check` : il échoue si une clé manque ou est en trop dans une langue.

## Contrôles automatiques

- `npm run check:i18n` : mêmes clés dans toutes les langues, aucune clé inutilisée.
- **Pseudo-langue** : ajouter `?pseudo` à l'adresse (ex. `http://localhost:5173/tabs/today?pseudo`). Chaque texte devient accentué, 40 % plus long et entouré de `⟦ ⟧`. Un texte sans crochets est écrit en dur dans le code ; un crochet coupé signale un libellé trop étroit pour une langue plus longue. Le test `e2e/i18n.spec.ts` vérifie tous les écrans principaux de cette façon.
- Tests du passage en anglais et en livres dans `e2e/i18n.spec.ts`.
